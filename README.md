## Recent projects

**Ex-Vero** (Code Cubicle 6.0): Offline-first edge memory kernel. It decides what a device should remember, trust and send to the cloud, using trust-weighted consensus across models and an explainable decision feed, built on Qdrant Edge.
[Repo](https://github.com/KA-1205/Ex-Vero)

**Panchnama** (Pixels to Products): Evidence app for NGO field photos. Photos are signed at capture, the backend re-verifies the signature, and originals are never overwritten. Built with Cloudinary, Supabase and Postgres, with object counts from YOLOv8 and ChangeFormer models.
[Repo](https://github.com/HackIndiaXYZ/pixels-to-products-cloudinary-ai-hackathon-2026-chaarwizards)

**FreqBridge** (FAR AWAY 2026): Multi-agent energy market simulation. A decentralized double-auction market modeling Japan's 50Hz/60Hz split-grid interconnection, driven by live weather data. I also debugged correctness issues in the market-clearing engine (a swing-equation ODE propagation bug, a converter-capacity mismatch and an agent-count discrepancy).
`Python` `FastAPI` `WebSockets`

**The Second Shift** (Build with Gemini): AI career re-entry coach for women returning to the workforce, with personalized skill-gap analysis and job matching.
[Live site](https://thesecondshift.vercel.app/) · [Repo](https://github.com/KA-1205/The-Second-Shift)

**EventGuard**: Real-time traffic incident command platform. A multi-objective knapsack solver (PuLP) that allocates limited emergency-response capacity under budget and coverage constraints, behind a Flask API and a Leaflet.js dashboard for a live ML-driven incident pipeline for Bengaluru.
`Flask` `Leaflet.js` `PuLP`
[Repo](https://github.com/TiyaGarg06/EventGuard)

**DistribuQ**: Distributed fault-tolerant task scheduler *(in progress)*. net/rpc node coordination, Raft-inspired leader election and fault recovery under simulated network partitions.
`Go` `net/rpc`
[Repo](https://github.com/TiyaGarg06/DistribuQ)

**LipiVerse**: Emotion-preserving multilingual poem translation, built during my GenAI internship at IGDTUW. It covers 3 Indian language pairs, with structured prompt pipelines that reduce semantic drift and keep tone and cultural nuance.
`Transformers` `Prompt Engineering`
